# 🚗 DriveLearn India

DriveLearn India is a modern web platform that connects learners with driving schools across India. It provides a centralized system for managing driving schools, instructors, learners, bookings, and administrative operations through dedicated role-based dashboards.

> **Status:** 🚧 Under Active Development

---

### 🌐 Public Website
- Responsive Landing Page
- Driving School Discovery
- Search & Browse Schools
- Contact & About Pages
- Dark / Light Theme

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/kaushikrajbongshi/drivelearn-india.git
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
